## English

A conversion for the first-generation YNDX-0008 without Zigbee. It combines local Bluetooth audio and a TV launcher with a remote-controlled voice overlay, voice alarms and hands-free Spotify playback. See the main repository for the source, the service USB pinout, the package inventory, the router VPN setup and signed APK releases.

## Русский

Переделка Яндекс Станции Макс первого поколения в Bluetooth-колонку и Android TV. Проверены звук, пульт, вызов голосовой панели поверх приложений, голосовой будильник и запуск личных «Любимых треков» Spotify с выключенным телевизором. Схема кабеля, инструкция, список сохранённых и удалённых пакетов, исходники и APK находятся в основном репозитории.
