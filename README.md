На Станции Макс **YNDX-0008 без Zigbee** работают Bluetooth, пульт, новый главный экран и голосовой ассистент. Проверили, что «Любимые треки» Spotify запускаются по команде даже при выключенном телевизоре. Руководство с распиновкой USB, список удалённых пакетов, исходники и релизы лежат в основном репозитории.
